### 🎯 CS2 AWP Network

A **Counter-Strike 2 AWP server network** built as a complete server ecosystem.

The project includes:

* 🖥️ **4 CS2 servers**
* 🗄️ Shared database
* 🎯 Custom gameplay systems
* 📈 Player progression
* 💰 Economy systems
* 🛡️ Administration tools
* 🌐 Community website
* 🔌 **19 first-party plugins**

The goal was to build an interconnected network rather than simply creating a collection of individual plugins.

🔗 **View the project:**
https://github.com/Gonlyxx/cs2-awp-network
