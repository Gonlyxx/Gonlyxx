### 🎯 CS2 AWP Network

A Counter-Strike 2 AWP server network project.

The project includes a multi-server setup with **4 CS2 servers**,
a shared database, custom gameplay systems, progression, economy,
administration tools and a community website.

The network includes **19 first-party plugins** and was designed as
a complete server ecosystem rather than just a collection of plugins.

🔗 **View the project:**  
https://github.com/Gonlyxx/cs2-awp-network
